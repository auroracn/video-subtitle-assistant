# 视频字幕一体助手

面向 Tampermonkey / Violentmonkey 的 MissAV 视频、字幕、磁力和 115 网盘辅助脚本。

## 主要功能

- 获取并下载最高分辨率视频，首次下载时选择本地缓存目录，视频分片保存到该目录，支持刷新页面后继续下载。
- 下载时可展开“连接详情”，查看并发连接、当前分片、连接主机、重试次数和最近失败。
- 下载完成后检测 fragmented MP4，并无损整理为更适合 115 转码的普通 MP4。
- 搜索磁力链接：保留 Sukebei、TorrentKitty、JavBus、BTDIG，并支持 Nyaa、Tokyo Toshokan 等站点。
- 磁力结果优先展示包含“破解”或“Reducing Mosaic”的结果，再按文件容量和分辨率排序。
- 搜索字幕、按当前番号严格匹配结果、预览字幕、按需筛选含中文内容的字幕，并在视频页面高亮当前选择。
- 在 115 页面查询番号对应的视频、播放 115 视频、保存字幕到同番号文件夹。
- 扫描多个本地目录，按目录优先级同步视频和字幕到 115，并显示上传状态、已有文件和排除列表。
- 本地同步最多同时处理 3 个文件；单个文件等待或失败不会阻塞其他文件，可单独停止或停止全部同步。
- 如果检测到其他窗口占用同步锁，面板提供“强制接管同步”；接管后旧窗口会停止当前任务，未完成文件保留待继续。
- 本地同步任务会保存到浏览器 IndexedDB；卡片提供独立的“刷新同步状态”按钮，页面刷新或 115 页面切换后可恢复未完成任务。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. 打开下面的脚本链接并安装：

   [安装视频字幕一体助手](https://raw.githubusercontent.com/auroracn/video-subtitle-assistant/main/%E8%A7%86%E9%A2%91%E5%AD%97%E5%B9%95%E4%B8%80%E4%BD%93%E5%8A%A9%E6%89%8B.user.js)

3. 按脚本管理器提示允许用户脚本运行。

## 基本使用

- 在支持的 MissAV 页面打开脚本面板，可进行视频下载、磁力搜索和字幕搜索。
- 首次下载或点击“设置缓存目录”时选择本地目录；视频分片会写入该目录，刷新后继续使用。浏览器数据库只保留任务索引等少量信息。
- 在 115 页面手动打开对应侧边栏，可查询番号、播放已有视频或进行本地文件同步。
- 本地同步优先复用已有视频的上级文件夹。目标 CID 留空时自动查找根目录下的“云下载”；只有目标为这个顶级“云下载”时才会复用或创建影片子目录，名称使用主要视频文件名并去掉后缀和末尾分集号。其他已有目录直接上传，禁止在根目录（CID `0`）创建或上传。
- 视频与字幕分别检查同名文件；已有 WMV 不会被当成 SRT 已存在。同步完成以目标文件夹中的实际文件为准。
- 上传后会每 60 秒核对一次 115 文件是否真正入库，最多核对 10 次；超时会标记失败并保留任务，可从同步卡片继续，不会永久停在“同步中”。
- 首次整理分片 MP4 时会加载浏览器端 FFmpeg 组件，之后会复用已加载的组件。

## 权限与隐私

- 脚本使用 `GM_xmlhttpRequest` 访问 115、字幕源、磁力站点及视频相关接口。
- 脚本使用用户授权的本地目录保存视频分片，使用 IndexedDB 保存任务索引、下载历史和目录授权；浏览器数据库仍会保存少量元数据。
- 选择本地目录并点击同步后，脚本才会读取并上传对应文件。
- 脚本不内置 115 Cookie、密码、Token 或其他账号密钥；115 操作依赖当前浏览器的登录状态。
- 当前脚本包含动态字幕地址所需的 `@connect *` 权限。安装前请自行审核源码和权限，确认信任后再使用。

## 已知限制

- 网站页面结构、115 接口或字幕源变化后，相关功能可能需要更新。
- 缓存目录依赖浏览器的 File System Access API；如果浏览器不支持目录授权，脚本不会开始新的分片缓存下载。
- 浏览器端 MP4 整理适合常规视频；超过 1.5 GiB 的分片视频会直接导出原始 MP4，缓存不会删除，但上传 115 可能仍需使用桌面版 FFmpeg 无损转封装。
- MP4 整理过程会显示读取、拼接、整理进度；异常或超时后可以在缓存保留的情况下重新导出。
- 实际上传和转码结果取决于当前 115 账号、浏览器登录状态及 115 服务端处理能力。
